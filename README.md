# Sitio web — Estudio Contable Bruschetti

Sitio web multipágina para presentar los servicios y la información institucional de un estudio contable. Este proyecto muestra experiencia en la construcción de sitios informativos para una actividad profesional.

## Secciones principales

- Presentación institucional.
- Servicios contables, impositivos y laborales.
- Preguntas frecuentes y enlaces útiles.
- Página de contacto.
- Diseño adaptable a distintos tamaños de pantalla.
- Acceso a contacto mediante enlaces y WhatsApp.

## Tecnologías

- HTML5
- CSS
- Bootstrap
- Bootstrap Icons
- JavaScript para componentes de interfaz

## Ejecutar localmente

Cloná el repositorio y abrí `index.html` en un navegador:

```bash
git clone https://github.com/cgldev/estudio-bruschetti.git
cd estudio-bruschetti
```

Para que los recursos se carguen correctamente, mantené la estructura de carpetas existente (`css/`, `js/` e `imgs/`).

## Alcance

El proyecto corresponde a un sitio informativo. No incluye un sistema propio de gestión contable ni procesamiento de trámites. Las consultas dependen de los medios de contacto configurados en el sitio.
